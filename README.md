# Telegram Monet Radical

A modern Material 3 Expressive theme generator specifically crafted for official Telegram (Android 8.0+ / Android 14 / 15 / 16 / 17).

## ✨ Features
- **Modern Telegram Engine**: Strictly tailored for modern Telegram official client specifications.
- **Frosted Glass (磨砂透明效果)**: Translucent blur styling applied to top folder bars, bottom navigation bar, message composer bar, and action bar with real-time blur mode.
- **Material 3 Expressive Color Theming**: High-contrast, expressive palettes that resolve contrast clashes and font invisibility when switching between apps or auto-night mode on Android 15/17.
- **Direct Save & Apply**: Single-tap to apply to Telegram or save `.attheme` directly to the `Downloads/TgMonet` folder.
- **Custom Palettes**: Extract dynamic M3 Expressive tonal palettes from wallpapers or custom colors.
- **No Legacy Baggage**: Deprecated Telegram X quirks and obsolete theme keys removed.
